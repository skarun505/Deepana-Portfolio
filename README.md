# Deepana Chandrasekar — Performance Marketer Portfolio

A modern, high-converting, mobile-first portfolio website for **Deepana Chandrasekar**, Performance Marketer specializing in Meta Ads, Google Ads, and LinkedIn Ads, managing **₹25L+ monthly cumulative ad budget** across 8 industries.

Live URL: [https://deepana-portfolio.vercel.app](https://deepana-portfolio.vercel.app)  
GitHub: [https://github.com/skarun505/Deepana-Portfolio.git](https://github.com/skarun505/Deepana-Portfolio.git)

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router, React 18, TypeScript)
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion (respects `prefers-reduced-motion`)
- **Icons**: Lucide React + custom inline brand SVGs
- **Fonts**: Google Fonts Sora (headings) & Inter (body)
- **Deployment**: Vercel ready (static pre-rendered)

---

## 🚀 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/skarun505/Deepana-Portfolio.git
   cd Deepana-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the port indicated in terminal) in your browser.

4. **Production Build**:
   ```bash
   npm run build
   npm run start
   ```

## 🌐 Deploy to Vercel

1. Push your repository to GitHub (`skarun505/Deepana-Portfolio`).
2. Log into [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import `skarun505/Deepana-Portfolio`.
4. Framework preset: **Next.js** (detected automatically).
5. Click **"Deploy"**.
